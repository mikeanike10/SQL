# SQL
A collection of advanced queries
This repository contains a curated collection of SQL queries developed in a professional fundraising analytics environment at a large nonprofit organization. The purpose of this work is to demonstrate advanced SQL proficiency, problem-solving ability, and a focus on improving operational efficiency through data.

OVERVIEW
The queries in this repository were designed to support day-to-day business needs, including data extraction, reporting, and process optimization. They reflect real-world use cases such as handling ad hoc stakeholder requests, troubleshooting data issues, and enhancing data accessibility for non-technical users.

USE CASES
Generating fundraising performance metrics and donor insights
Supporting ad hoc analytical requests from stakeholders
Debugging and enhancing existing data pipelines
Preparing clean, structured datasets for visualization tools

PURPOSE
This repository highlights the practical application of SQL in a fast-paced business environment, emphasizing both technical depth and the ability to deliver actionable insights efficiently.
